# Pemburu Bintang Nebula — modifikasi dari Star Catcher
Pemburu Bintang Nebula adalah game arcade yang mengharuskan pemain mengumpulkan bintang sebanyak mungkin dan menghindari meteor selama 45 detik. Pemain mengendalikan pesawat untuk menangkap bintang kuning yang memberikan 15 poin dan menghindari meteor yang akan mengurangi satu nyawa. Permainan berakhir ketika waktu habis atau pemain kehilangan seluruh tiga nyawa.

## Menjalankan
Ekstrak ZIP. Buka folder di VS Code lalu jalankan index.html dengan Live Server. Alternatif: `python -m http.server 8000` lalu buka http://localhost:8000. index.html juga dapat dibuka langsung untuk contoh ini.

## Kontrol
- Panah Kiri (←) / A: Menggerakkan wadah ke kiri.
- Panah Kanan (→) / D: Menggerakkan wadah ke kanan.
- Tombol ◀ Kiri / Kanan ▶: Menggerakkan wadah melalui tombol di layar untuk pengguna HP. Tekan dan tahan tombol untuk bergerak.
- Enter / Tombol Mulai Permainan: Memulai atau mengulang permainan.
